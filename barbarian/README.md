# Barbarian

A tribute to the 1987 Atari ST sword-fighting game. Open `index.html` in a browser — no build step and no assets. Every sprite, backdrop and sound is generated in code.

It runs like the ST: a 320×200 screen with 3-bit-per-channel colour, shown at 4:3 and running at 50 Hz.

## Play

| Key | Action |
| --- | --- |
| `1` / `2` / `D` | One player, two players, demo |
| `P`, `M`, `Esc` | Pause, mute, back to title |
| Player 1 | `W A S D` (+ `Q E Z C` diagonals), fire `Space` |
| Player 2 | Arrows (+ numpad diagonals), fire `Enter` |

In one-player mode, either key set controls you. Gamepads and touch controls also work.

## Moves (facing right)

| Fire + | Move | | No fire | Move |
| --- | --- | --- | --- | --- |
| Up | Overhead chop | | Up | Jump |
| Up-forward | Neck chop | | Down | Crouch |
| Forward | Body chop | | Forward / back | Walk |
| Down-forward | Leg chop | | Up-back | Guard head |
| Down | Kick | | Down-back | Guard body |
| Down-back | Web of death | | Down-forward | Roll |
| Back | Flying neck chop | | | |
| Up-back | Head butt | | | |

The flying neck chop takes the opponent's head off if it lands clean. Crouch under neck-height blows, jump over leg chops, and guard to parry.

## Features

- One-player campaign: 8 increasingly skilled barbarians across the forest and the wasteland, then Drax in his lair. Defeat him to free Princess Mariana.
- Six-orb energy bars with snakes that bite the orbs away, a 60-second timer and a saved high score.
- Decapitations, and the goblin who kicks the head away and drags the body off.
